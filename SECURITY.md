# Security

Please report security problems privately. Use **Report a vulnerability** on the repository's
[Security tab](https://github.com/saroj-shahi/vibecheck/security/advisories/new), not a public issue.

Include the macOS version, the VibeCheck version (Settings → About) and the steps to reproduce. You'll get a
reply within a week. Only the latest release gets fixes.

Install VibeCheck only from this repository's releases, the official Homebrew tap (`saroj-shahi/tap`) or the
install script in `scripts/install.sh`. Each release publishes a SHA-256 checksum next to `VibeCheck.zip`.
