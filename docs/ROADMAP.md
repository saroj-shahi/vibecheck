# VibeCheck roadmap

What's planned for VibeCheck, highest priority first. **P1** soon · **P2** nice to have · **P3** someday ·
**Tech debt** ongoing upkeep. Ideas and bug reports are welcome as
[issues](https://github.com/saroj-shahi/vibecheck/issues). How the app is built and why:
[DEVELOPMENT.md](DEVELOPMENT.md).

## Backlog

| # | Item | Priority | Notes |
|---|---|---|---|
| 1 | Clipboard spike: what macOS 26+/27 pasteboard privacy does to a background reader (`NSPasteboard.accessBehavior`, the "Paste from other apps" prompt) when polling `changeCount` | P1 | Decides whether history is possible without a prompt on every copy. If it prompts, history becomes "record while the deck is open" or is dropped; snippets still ship |
| 2 | Clipboard history store (`App/ClipboardHistory.swift`): poll `changeCount` every 0.5 s; keep the last 50 text (≤64 KB), image (≤5 MB) and file items with source app and time; dedupe | P1 | **Off by default.** Never records `org.nspasteboard.ConcealedType` / `TransientType` / `AutoGeneratedType`, anything copied while Secure Input is on, or apps on an ignore list (password managers preset). Memory only unless "keep across restarts" is on |
| 3 | Clipboard in ⌘K: a "Clipboard" section (and a `clip` filter), ↩ puts the item back and pastes into the previous app; ⌘↩ actions: paste as plain text, pin, delete; optional global shortcut opens the palette in clipboard mode | P1 | Auto-paste posts ⌘V, which needs Accessibility; without it ↩ only copies and says "Copied, press ⌘V". Ask for Accessibility only on first use |
| 4 | Pinned snippets: pin from history or add in Settings; shown first in the Clipboard section; stored on disk and included in settings backup (add the key to `SettingsBackup`) | P1 | Snippets are typed or pinned on purpose, so they persist even with history off |
| 5 | Settings → Clipboard page: on/off, history length, keep across restarts, ignored apps, clear history, manage snippets; ⌘K "Clear clipboard history" | P1 | Needs a security review of items 2–5 (reads possibly sensitive data) |
| 6 | Find my cursor: ⌘K command and optional shortcut; a click-through ring flashes around the pointer (0.8 s, a fade with Reduce Motion) | P2 | No permissions. One borderless panel on the pointer's screen |
| 7 | Keyboard cleaning mode: ⌘K "Clean keyboard" swallows key, modifier and media-key events for 45 s with a countdown overlay; click "Done" on the overlay to end early | P2 | `CGEventTap`, needs Accessibility (asked on first use). Can't block Touch ID / power key; say so on the overlay. Needs a security review (acts on input) |
| 8 | App Shortcut phrases out of code into `AppShortcuts.xcstrings` | P2 | Needs `build.sh` support and a check with a built app |
| 9 | Translations | P2 | None yet |
| 10 | Private-API recheck after each macOS update: `IOHIDEventSystemClient*`, `responsibility_get_pid_responsible_for_pid`, SMC `PSTR`/`PDTR`/`F0Ac`, `IOBluetoothPreference{Get,Set}ControllerPowerState` | Tech debt | Last checked 2026-11-19 on macOS 27.2.1 (26B131), M5: all working (`--dump` + a `dlsym` probe) |
| 11 | Website / landing page from the brand assets | P3 | Not started |

## Not planned

- Window management, Dock tweaks, file tools, screenshots and screen recording, an uninstaller, lyrics, a
  "Dynamic Island" bar, and API cost estimates.
- Anything that needs input monitoring: a mouse jiggler, scroll direction per device, typing stats, key
  remapping.
- Fan control, a disk cleaner, a calendar in the Clock panel, keep awake with the lid closed, a sandboxed
  App Store edition, display brightness, iCloud settings sync, and a dark mode toggle.
