# Code of Conduct

VibeCheck follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, assume good intent, and keep discussion about the work. Harassment, insults
and personal attacks aren't welcome in issues, pull requests or anywhere else in this project.

To report a problem privately, contact the maintainer through their [GitHub profile](https://github.com/saroj-shahi).
Reports are kept confidential.
